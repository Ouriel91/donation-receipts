# Claude entry point

Before starting a Code Review, open and read `docs/RULES.md` and `docs/CLAUDE_WORKFLOW.md`. Follow their shared rules and review workflow, and inspect the defined version, including untracked files. In Code Review, do not change files or perform Git state-changing actions without explicit authorization; a separately assigned future task may define another role. Report concrete findings and test limits without exposing credentials or real donor data. Commit, push, PR, and merge require explicit authorization unless already authorized for the action; see `docs/RULES.md`.
